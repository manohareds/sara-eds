# Panel Image Double Block

Displays two images side by side in a clean panel layout.

## Purpose

A simple two-column image showcase block, matching the Figma "Panel Image Double" component. Used for visual storytelling or feature highlights.

## Authoring

One row with two columns, each containing an image:

| Panel Image Double | |
|---|---|
| Image 1 | Image 2 |

## Behavior

- Stacks vertically on mobile, side by side on tablet+
- Images are optimized via createOptimizedPicture
- 48px gap between images, 64px padding around the panel
