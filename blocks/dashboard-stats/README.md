# Dashboard Stats Block

Displays key metrics as stat cards in a responsive grid layout.

## Purpose

Shows KPI summary cards with label, value, trend indicator, and optional icon. Designed for SaaS dashboard overview sections.

## Authoring

Each row in the block table is a stat card with two columns:

| Column 1 | Column 2 |
|----------|----------|
| Label + Value + Change (line-separated) | Icon (optional) |

## Behavior

- Cards display in a 3-column grid on desktop, 2 on tablet, 1 on mobile
- Positive changes (↑) are styled green, negative (↓) red
- Bordered card design with subtle spacing
