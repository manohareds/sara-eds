# Card Grid Icon Block

Displays a grid of cards, each with a circular icon and text content.

## Purpose

Feature grid with icon + title + description per card. Matches the Figma "Card Grid Icon" component. Used for showcasing features, benefits, or capabilities.

## Authoring

Each row is a card with two columns: icon and text content.

| Card Grid Icon | |
|---|---|
| :info: icon | **Title**<br>Body text description |
| :info: icon | **Title**<br>Body text description |

## Behavior

- 1 column on mobile, 2 on tablet, 3 on desktop
- Icons displayed in circular borders
- 40px gap between rows, 48px between columns
